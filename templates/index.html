About the Platform

What is ExamGuard AI?

Traditional remote assessments often force institutions into a difficult tradeoff: install intrusive spyware software on student machines, or accept unmonitored tests prone to academic dishonesty. ExamGuard AI bridges this gap with an open, privacy-conscious web architecture.

The Problems We Aim to Solve

  • Heavy native app requirements that crash standard student Chromebooks or low-spec laptops.
  • Unclear cheating allegations based on opaque algorithmic scoring without audit evidence.
  • Time-consuming manual question authoring and slow, error-prone paper grading workflows.
Eliminates invasive desktop installations

The ExamGuard AI Solution

  • Zero-Install Edge AI: Computer vision models execute directly in standard modern web browsers via TensorFlow.js.
  • Verifiable Evidence: Timestamped snapshots and event logs provide teachers with clear factual records.
  • Flexible Policies: Instructors can turn video proctoring completely OFF when camera monitoring is not required.
Fair, transparent, and respectful of candidate privacy

Defensible Security

Realistic Security & Data Protection

ExamGuard AI adheres to practical defense-in-depth engineering principles. We avoid unrealistic 100% security claims, focusing instead on verifiable technical safeguards and candidate privacy.

Edge Privacy Architecture

Webcam streams are analyzed locally on the candidate's device via TensorFlow.js. Video frames are not continuously uploaded to cloud servers, protecting student privacy.

Defense-in-Depth Headers

Enforces strict Content Security Policy (CSP), HTTP Strict Transport Security (HSTS), X-Frame-Options DENY, and CSRF protection across all state-changing endpoints.

Indexing Protection

All student submissions, candidate reports, and tutor dashboards are strictly protected by session authentication and protocol-level X-Robots-Tag: noindex, nofollow headers.

Support & FAQ

Frequently Asked Questions

Answers to common questions about ExamGuard AI examinations, privacy, and proctoring technology.

What is ExamGuard AI?

ExamGuard AI is a secure web-based examination platform designed for educators and institutions. It automates test creation, delivers timed assessments, and provides multi-sensor proctoring with tamper-evident audit trails.

How does client-side proctoring protect student privacy?

Proctoring detection models (such as BlazeFace and COCO-SSD) run locally inside the student's web browser using TensorFlow.js. Video streams are analyzed on-device rather than continuously uploaded, minimizing bandwidth and safeguarding student privacy.

Can exams be run without webcam requirements?

Yes. Tutors can configure exams with Video Proctoring toggled OFF. When disabled, candidates take assessments without webcam permission prompts, desk setup, or facial recognition steps.

How are proctoring events reviewed?

Any flagged events (such as multiple faces, tab switching, or unauthorized devices) are logged with exact timestamps and evidence snapshots in the tutor portal, giving educators objective data for integrity decisions.

How does AI question generation work?

Instructors can upload course syllabi or textbook notes. Integrated AI models (Google Gemini and Groq) draft multiple-choice questions with answer choices and mathematical formula syntax for instructor review.

Do students need to install software?

No installation or browser extensions are required. ExamGuard AI operates entirely within modern web browsers (Chrome, Edge, Firefox, Safari) on laptops, desktops, and Chromebooks.
